# Normalized habit data

Generated by `python3 scripts/normalize.py` from `Loop Habits CSV/` (a Loop Habit Tracker export). Re-running overwrites `data/`.

## habits.csv — one row per habit

| column | meaning |
|---|---|
| position | order in the app |
| name | habit name, also the column name in the yearly files |
| color | colour set in the app |
| times, per_days | target: `times` check-ins every `per_days` days (1/7 = once a week, 5/7 = five times a week, 1/30 = once a month) |
| start | first day the habit has any entry |
| archived | archived in the app |

## &lt;year&gt;/checkmarks.csv — one row per day

`date`, then one column per habit:

- `done` — marked done that day
- `auto` — not marked, but kept: Loop fills the day in because the target for that week/month is already met
- `no` — explicitly marked as not done (rare)
- empty — nothing marked, or the habit hadn't started yet (see `start`)

Days after the export date, which Loop fills in ahead, are dropped.

## &lt;year&gt;/scores.csv — one row per day

`date`, then one column per habit: Loop's habit strength, 0–1 (4 decimals). Empty before the habit's start.
